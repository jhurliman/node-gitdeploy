# gitdeploy — deprecated

**Do not use this package. It is no longer maintained, and no further releases or security fixes are planned.** This repository is archived as a historical reference.

`gitdeploy` was a small webhook listener that ran Git updates and deployment commands on a server. Its original dependency stack and unauthenticated webhook design are unsuitable for current production deployments. The proposed 2.0 modernization has been discontinued.

Migrate deployment automation to your maintained CI/CD platform, with authenticated triggers, controlled credentials, and deployment permissions appropriate to your application. Disable existing gitdeploy listeners after migrating.

The source and history remain available for reference; archiving does not remove previously published npm versions or make them safe to use.
